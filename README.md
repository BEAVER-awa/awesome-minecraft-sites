## 使用提示

1. **下载资源认准加载器与版本**：模组注意区分 Forge / Fabric / NeoForge 以及对应的 MC 版本。
2. **安全提示**：警惕非官方渠道的"破解版""永久会员"宣传，优先 CurseForge / Modrinth 等正规平台。
3. **国内访问**：部分站点需科学上网；版本与资源加速推荐 BMCLAPI 镜像。
