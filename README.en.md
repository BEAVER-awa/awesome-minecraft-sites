## Usage notes

1. **Match the loader and version when downloading**: for mods, check Forge / Fabric / NeoForge and the corresponding MC version.
2. **Safety**: be wary of "cracked" or "lifetime membership" offers from unofficial channels; prefer reputable platforms such as CurseForge / Modrinth.
3. **Access from mainland China**: some sites require a VPN; BMCLAPI is recommended as a mirror for versions and assets.
